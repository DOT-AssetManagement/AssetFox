# Welcome to AssetFox!
This application is designed and maintained by PennDOT Asset Management for DOT's, Agencies and municipalities who wish to optimize their infrastructure investment and forecast conditions into the future. This application was initially designed for DOT inventory level bridge and pavement assets, but can be applied to any class of asset, including trucks, pipes or buildings. For more information on the platform, please contact Justin Bruner, P.E. at jbruner@pa.gov
